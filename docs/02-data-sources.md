# FinAgent 数据源选型笔记

> 记录"金融数据从哪来"的讨论结论：为什么用 AkShare、有哪些替代方案、将来怎么升级。

## 1. 获取金融数据的几种方式

### 方式 1：免费 Python 库
| 库 | 特点 | 适合 |
|---|---|---|
| **AkShare**（本项目在用）| 免费、接口全（行情/财务/新闻）、无需 key、国内直连 | 个人/教学/演示 |
| Tushare | 免费版有积分门槛，Pro 版更全 | 进阶 |
| baostock | 免费、历史数据规范，无实时 | 历史回测 |

### 方式 2：付费/商业数据源（真实工作常见）
| 源 | 特点 | 谁在用 |
|---|---|---|
| Wind（万得）| 国内机构标准，最权威 | 券商/基金/机构 |
| 同花顺 iFinD | 国内主流，接口成熟 | 投研 |
| 东方财富 Choice | 行情/数据全 | 机构 |
| Bloomberg | 全球标准 | 外资金融 |

### 方式 3：交易所/官网接口
- 上交所/深交所官网数据接口（免费但难用、不规范）

### 方式 4：本地数据文件
- 下载历史行情 CSV 到本地自行管理

## 2. 本项目的选择逻辑

| 对比项 | AkShare | 付费商业源（Wind 等）|
|---|---|---|
| 成本 | 免费 ✅ | 几万/年 ❌ |
| 接口全面度 | 够演示 ✅ | 更专业 |
| 稳定性 | 偶有变动 ⚠️ | 稳定 |
| 简历话术 | 「免费接口快速验证」| 「生产环境可替换 Wind」|

**结论**：
1. 现在用 **AkShare**——免费、无需 key、国内直连，适合学习和演示。
2. 生产环境可替换 Wind/同花顺——**工具函数封装在 `agents/tools.py`，换数据源只改函数内部，Agent 不用动**（低耦合设计）。

## 3. 为什么现在不换

1. 商业源要钱（Wind 个人版几万/年）
2. Tushare 需要积分，AkShare 门槛最低
3. 项目重点是 Agent 编排 + RAG，数据源是"工具"，够用就行

## 4. 面试话术

> 「用免费 AkShare 快速搭建数据层，工具层做了封装，生产环境可平滑替换为 Wind/同花顺等商业数据源。」
