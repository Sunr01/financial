# FinAgent 重要问答（三）：数据与 AI 功能

> 近期关于数据、RAG、回测、前端的重要问答。

## 1. 为什么数据源要多源 + 重试？

- 单一数据源可能限流/不稳定（东财曾断连一天）。
- **多源备份**：行情=新浪、K线=腾讯、财务/新闻=东财。
- **重试容错**：`_retry` 失败重试 2 次。
- 不同源代码格式：新浪/腾讯带前缀（sh600519），东财不带。

## 2. 为什么 K 线数据要缓存？

- 多股回测每次拉很多次数据，重复请求慢。
- 内存缓存 `_kline_cache`：拉过一次不再拉。
- 企业级可升级 Redis/文件缓存。

## 3. 收益曲线图有哪几条线？

- 策略收益（红）/ 基准收益（黄）/ **相对收益率**（蓝）
- 最大回撤区间用 markArea 阴影标注
- 前端 ECharts：可缩放、悬停显示数值

## 4. 绩效指标有哪些？怎么算？

- 累计/年化/夏普/最大回撤/胜率/盈亏比/波动率/相对收益
- 年化 = (1+总收益)^(252/天数)-1
- 夏普 = (年化-无风险)/年化波动率
- 波动率 = 日收益标准差×√252
- 回撤 = (当前-峰值)/峰值

## 5. 多股票回测怎么选股？

- 因子排序（动量=近20日涨幅 / 成长 / 波动率）
- 持仓 N 只（等权）→ 每日换仓
- 无未来函数：用**截至当天**的数据算因子（`df.iloc[:idx+1]`）

## 6. 为什么前端 SPA + ECharts？

- SPA：单页应用，导航切换不刷新（体验好）
- ECharts：动态 K 线/收益曲线（缩放、悬停）
- 前后端分离：frontend/ 独立目录

## 7. 会话管理为什么用 PostgreSQL？

- 会话列表/保存/重命名/删除需要持久化
- conversations 表（messages JSONB）按用户隔离
- 前端：侧栏可隐藏、默认加载最近会话

## 8. 追问"那2024年呢"怎么处理？

- 用 Checkpointer 保存上一轮意图（prev_intent）
- 提示词明确"追问应与上一轮意图一致"
- 非法意图兜底为 rag（VALID_INTENTS 校验）
