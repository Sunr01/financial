# FinAgent 知识点问答（二）：git / 前端 / 数据与部署

> 开发过程中遇到的"为什么"与"是什么"，整理成问答方便复习与面试。

## 1. git 和 GitHub 有什么区别？

- **git**：本地的版本管理工具，`add/commit` 不需要联网。
- **GitHub**：云端存放代码的网站，`push/pull` 才需要它。
- **一句话**：git 本地存档，GitHub 云端备份+展示。

## 2. git init / add / commit / push 是什么？

| 命令 | 通俗理解 |
|---|---|
| `git init` | 给项目建档（只做一次）|
| `git add .` | 把文件放进"待上传清单"（遵守 .gitignore）|
| `git commit -m "说明"` | 打包成"快照"存档（必须写说明）|
| `git push` | 把存档上传到 GitHub |

## 3. .gitignore 是什么？需要每次手动更新吗？

- **上传黑名单**：列出的类型永远不会被上传。
- **按类型忽略**（不是按文件）：配置一次，同类型永远跳过。
- **何时才要更新**：出现全新类型的生成物/密钥/缓存时。
- **关键坑**：已上传过的文件，加 gitignore 不会自动删，要 `git rm -r --cached` 停止跟踪再 push。

## 4. `git rm -r --cached` 是干什么的？

- 从 git 跟踪中移除文件，**但保留本地文件**。
- 用途：让"已上传过但想本地私有"的文件停止被 git 管理。
- 之后 commit + push，GitHub 上就删掉了。

## 5. git 被 Push rejected（远程有改动）怎么办？

- 原因：GitHub 上有本地没有的提交。
- 解决：**Merge（合并）**远程改动到本地，再 push。
- 不要选 Rebase（新手易乱历史）。

## 6. 误删文件怎么找回？

- **git 历史有**：`git checkout HEAD -- 文件夹名` 恢复。
- **git 历史没有**（从未提交过）：查回收站，或重建。
- **教训**：重要文件尽早 commit，git 历史就是"后悔药"。

## 7. 前端三件套是什么？

- **HTML**：页面结构（骨架）。
- **CSS**：样式（美化）。
- **JS**：逻辑（交互）。
- 标准做法是分开文件（index.html / style.css / app.js），不塞一起。

## 8. 前端怎么和后端通信？

- `fetch("/chat", {method:"POST", body: JSON.stringify({question: q})})` 调后端接口。
- 后端（FastAPI）返回 JSON，前端 `resp.json()` 解析显示。
- **await** = 等待异步结果。

## 9. ECharts 动态K线和静态图片的区别？

- 静态图片：后端生成 PNG，前端显示（不能交互）。
- **ECharts 动态图**：后端返回数据 JSON，前端画图——可缩放、悬停显示数值（开/收/低/高/量）。
- **数据格式**：K线要求 `[开, 收, 低, 高]` 数组（ECharts 固定顺序）。

## 10. FastAPI 装饰器和接口是什么？

- `@app.post("/chat")` = 给函数贴标签，声明它是 HTTP 接口。
- 客户端 POST 到 /chat → 函数被调用 → 返回 JSON。
- `BaseModel` 定义请求体结构，FastAPI 自动校验。

## 11. 数据源为什么选多个？（新浪/腾讯/东财）

- 单一数据源可能限流/不稳定（东财曾持续断连一天）。
- **多源备份 + 重试容错**：行情=新浪、K线=腾讯、财务/新闻=东财。
- 代码格式不同：新浪/腾讯带前缀（sh600519），东财不带（600519）。
- **低耦合**：数据获取封装在 tools.py，换源只改内部，上层无感。

## 12. 前端页面在项目里放哪？

- 独立 `frontend/` 文件夹（前后端分离），后端 FastAPI 挂载它。
- 后端 `app.mount("/", StaticFiles(...))` 指向 frontend 目录。
- **注意**：API 接口要先定义，再挂载静态目录（否则路由被吞）。
