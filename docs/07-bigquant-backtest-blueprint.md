# 完整复刻 BigQuant 成长因子策略分析（后续实现参考）

> 分析"做成一模一样的 BigQuant 价值成长因子策略"的可行性、实现路径、优缺点。当前未实现，留档备用。

## 1. 目标策略（BigQuant 原版）

- **策略逻辑**：持仓 10 只票，每日用 stockranker 模型根据市值、成长等因子预测排序后换仓 1 只。
- 已剔除 ST、退市、科创板股票。
- **绩效**（原页面）：累计收益 131.71%、年化 23.40%、夏普 1.34、最大回撤 9.40%、胜率 51.55%。
- **页面组成**：策略概览（今日收益/年化/累计/作者/股票池）+ 绩效指标（累计/年化/基准/阿尔法/贝塔/夏普/胜率/盈亏比/波动率/回撤）+ 收益曲线图（可缩放）+ 源码展示。

## 2. 难度拆解：钱/数据 vs 工程

| 部分 | 内容 | 成本 |
|---|---|---|
| **数据壁垒** | 几百个因子数据、stockranker 模型、user_factor 因子表 | 商业数据源（Wind/聚宽等）几万/年，或独家数据 |
| **工程部分** | 回测引擎、调仓逻辑、绩效指标、曲线图、源码页 | ✅ 免费，可用现有技术栈实现 |

**结论**：代码框架/回测/指标/页面可 1:1 复刻；因子精度取决于数据源（免费数据只能近似）。

## 3. 免费数据的"近似实现"方案

### 3.1 简化因子（用 AkShare 真实数据）
| 因子 | 数据来源 | 说明 |
|---|---|---|
| 市值 | AkShare 实时行情（总市值字段）| 真实 |
| 成长性（营收增速）| 财务摘要接口 | 真实 |
| 估值（PE/PB）| 行情/财务计算 | 可算 |

### 3.2 参考策略逻辑（与原版一致）
```
股票池（如20只，剔除ST/退市/科创板）
  → 用"小市值 + 高营收增速"打分排序（近似 stockranker）
  → 每日选前10只持有
  → 每日换仓 1 只（卖出得分最低的，买入新进前10的）
  → 等权分配资金
```

## 5. 优缺点

### 近似实现（免费数据）
- **优点**：免费、真实数据、逻辑框架与原版一致、能演示回测全流程
- **缺点**：因子精度低（无 stockranker 几百因子），选股效果不如原版；收益曲线与真实策略有差距

### 完整复刻（商业数据）
- **优点**：因子全、模型准、效果接近原版
- **缺点**：数据源年费几万（Wind/聚宽）；需要训练 stockranker（历史因子+标签）；维护成本高
